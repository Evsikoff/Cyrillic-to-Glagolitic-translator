# Кириллица ↔ Глаголица — VK Mini App

Клиентский переводчик с кириллицы на глаголицу и обратно. Введённый текст
обрабатывается локально и не отправляется на сервер.

## Что адаптировано для VK Mini Apps

- VK Bridge инициализируется событием `VKWebAppInit`.
- Параметр запуска `vk_platform` определяет среду клиента.
- Светлая/тёмная тема и системные панели синхронизируются с конфигурацией VK.
- Безопасные отступы клиента и устройства учитываются на всех сторонах экрана.
- Копирование выполняется через `VKWebAppCopyText` с браузерным резервным
  вариантом.
- Заголовок приложения передаётся клиенту через `VKWebAppSetTitle`.
- Приложение сохраняет работоспособность при открытии в обычном браузере.
- Рекламный блок имеет видимую маркировку; юридическая маркировка и `erid`
  также находятся на исходном изображении.

## Локальный запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Проверки и production-сборка:

```bash
npm run check
```

Готовые статические файлы появятся в каталоге `dist`.

## Публикация во ВКонтакте

1. Создайте мини-приложение в кабинете разработчика VK.
2. Выполните `npm run build`.
3. Разместите содержимое `dist` на хостинге VK Mini Apps или другом HTTPS-хостинге.
4. Укажите production URL и URL для разработки в настройках приложения.
5. Проверьте приложение внутри VK на desktop web, Android и iOS, в светлой и
   тёмной темах и обеих ориентациях экрана.
6. Перед модерацией заполните описание, категорию, иконки, обложки, контакты и
   ссылку на политику конфиденциальности в кабинете приложения.

Если в будущем появится серверная часть, она должна проверять подпись `sign`
параметров запуска до доверия к `vk_user_id` и другим параметрам.
